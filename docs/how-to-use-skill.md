# 知識をまとめてデプロイするスキルの使い方

このリポジトリには「調べた内容をまとめてデプロイする」ワークフローが **Cursor Rules** として設定されています。

## どんなスキルか

Cursorで調べた内容や会話でまとめた知識を、**1回の指示でドキュメントページとして公開**できます。

```
Cursorへの指示 → ページ作成 → GitHubプッシュ → Vercel自動デプロイ
```

## 使い方

### iPhoneからの操作手順

1. **Cursorのチャット**（またはCloud Agent）を開く
2. 以下のように指示する：

```
〇〇についてまとめてデプロイして
```

```
今話した内容をサイトに追加して
```

```
「Reactのhooksとは何か」についてページを作ってプッシュして
```

3. Cursorが自動で：
   - Markdownファイルを作成
   - `git commit & push`
   - Vercelが自動デプロイ（約1〜2分）

### 指示のコツ

| やりたいこと | 指示の例 |
|-------------|----------|
| 今の会話をまとめる | 「今話した内容をサイトにまとめてデプロイして」 |
| 新しいトピックを追加 | 「〇〇について調べてまとめてデプロイして」 |
| カテゴリを指定 | 「iphone-devフォルダに〇〇のページを追加してプッシュして」 |
| 既存ページを更新 | 「step2-cursor.mdに〇〇の内容を追加してプッシュして」 |

## スキルの設定ファイル

スキルは `.cursor/rules/deploy-knowledge.mdc` に定義されています。

このファイルに、Cursorエージェントが従うべきワークフローと品質ガイドラインが書かれています。

## スキルをカスタマイズするには

`.cursor/rules/deploy-knowledge.mdc` を編集して：

- 新しい **コンテンツの種類** を追加
- **フォルダ構造** のルールを変更
- **品質ガイドライン** を追加

CursorのCloud Agentに「deploy-knowledge.mdcの〇〇を修正して」と指示するだけで変更できます。
