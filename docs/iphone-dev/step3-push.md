# ステップ3: コードをプッシュする

## Cloud Agentが自動でプッシュする場合

Cursor の Cloud Agent を使っている場合、Agentがコード変更後に自動でプッシュします。  
特に操作は不要です。

## GitHubアプリで確認する

1. GitHubアプリを開く
2. リポジトリを選択
3. **「Code」** タブでファイルが更新されているか確認

## Vercelが自動でデプロイを開始する

プッシュが完了すると、GitHubからVercelに通知が届き、**自動でビルド＆デプロイが始まります**。

```
push完了 → Vercel検知 → ビルド開始 → デプロイ完了（約1〜2分）
```

:::info
GitHubの **「Actions」** タブや、Vercelのダッシュボードでビルドの進行状況を確認できます。
:::

## プッシュが失敗した場合

Cursorのエージェントに以下のように伝えてください：

```
プッシュに失敗しました。原因を調べて再試行してください。
```
