# ステップ1: GitHubでリポジトリを作成する

## GitHubアプリをインストールする

1. App Store で **GitHub** アプリをダウンロード
2. GitHubアカウントでログイン（アカウントがない場合は [github.com](https://github.com) で無料登録）

## リポジトリを作成する

1. GitHubアプリを開く
2. 右上の **＋** ボタンをタップ
3. **「New repository」** を選択
4. 以下を入力する：
   - **Repository name**: わかりやすい名前（例: `my-cursor-notes`）
   - **Description**: サイトの説明（任意）
   - **Visibility**: `Public`（Vercel無料プランで使用する場合）
5. **「Create repository」** をタップ

## 確認

リポジトリが作成されると、URLが発行されます。

```
https://github.com/あなたのユーザー名/リポジトリ名
```

このURLを控えておいてください。次のステップで使います。

:::tip
リポジトリ名は英数字・ハイフン・アンダースコアが使えます。スペースは使えません。
:::
