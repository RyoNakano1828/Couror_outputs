# Cursor 知識ベース

iPhoneだけで開発・デプロイする方法をまとめたドキュメントサイトです。

## 使用技術

- [Docusaurus](https://docusaurus.io/) - ドキュメントサイトフレームワーク
- [Vercel](https://vercel.com/) - ホスティング・自動デプロイ
- [Cursor](https://cursor.com/) - AI搭載開発環境

## ローカル開発

```bash
npm install
npm start
```

## デプロイ

`master` ブランチにプッシュすると Vercel が自動でデプロイします。
